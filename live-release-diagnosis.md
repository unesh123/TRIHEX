## Deployment facts

The live domain is served by Vercel. This repository has `vercel.json` but no committed `.vercel/project.json` linkage and no authenticated Vercel CLI available in this environment. Therefore production deployment requires linking or authenticating to the actual Vercel project; pushing GitHub commits alone currently cannot publish the release.

## Recommended correction

1. Link the Vercel project to the `unesh123/TRIHEX` GitHub repository and set production branch to `main`, **or** authenticate the Vercel CLI to the current TRIHEX Vercel project and deploy from this repository.
2. Ensure all production environment variables from `PHASE0_PRODUCTION_RUNBOOK.md` exist in the Vercel project before promoting the quote migration-dependent release.
3. Apply `drizzle/0003_quote_workflow.sql` against the production database, then deploy commit `86b2ac8`.
4. In the local browser, test once in Incognito with extensions disabled. The `__processed_*` body attribute must disappear; it is not generated by TRIHEX source.
